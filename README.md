# wn-ts

Bringing Open Multilingual Wordnet to the web.

## Overview

This work is done independently of the Global Wordnet association. Just trying to improve accessibility to the data, and leverage it on the web.

Some possible use cases:
1. simple multi-lingual dictionaries
2. use definitions for crossword puzzles and other games
3. methods to explore relationships of words
