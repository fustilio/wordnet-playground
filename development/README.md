# Development Tools and Benchmarks

This directory contains development tools, benchmarks, and experimental features for the WordNet TypeScript ecosystem.

## 📁 **Directory Structure**

- **`benchmark/`** - Performance testing and library comparisons
- **`sqlite-opfs-demo/`** - SQLite OPFS browser demo  
- **`wn-pybridge/`** - Python bridge for cross-language testing

## 🎯 **Purpose**

The projects here are not part of the "core" but serve as useful projects that either have helped us test out certain ideas or some comparisons that were useful. Left here for posterity and continued development.
