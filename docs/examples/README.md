# Examples

Working examples for the WordNet TypeScript ecosystem.

## Quick Start

```bash
# Web demo
cd examples/web/web-developer-demo
pnpm install && pnpm dev

# Node.js demo  
cd examples/node/wn-ts-node-demo
pnpm install && pnpm run all-use-cases

# CLI examples
npm install -g wn-cli
wn-cli search "computer" --lexicon oewn:2024
```
